# Предсказание стоимости автомобилей с пробегом

## Задача проекта  
Тип задачи: **регрессия**  
Целевая метрика: **RMSE ≤ 2500**  

## Описание задачи  
Сервис «Не бит, не крашен» разрабатывает приложение для оценки рыночной стоимости автомобилей с пробегом. Цель проекта — построить модель, которая поможет быстро и точно определять стоимость автомобиля на основе его характеристик.  

## Навыки и инструменты  
- **Подготовка данных**:  
  - Очистка пропусков и аномалий (например, неверные года регистрации).  
  - Кодирование категориальных признаков (**OneHotEncoder**, **LabelEncoder**).  
  - Генерация новых признаков (например, возраст автомобиля).  
- **Модели машинного обучения**:  
  - **LinearRegression**  
  - **DecisionTreeRegressor**  
  - **CatBoostRegressor**  
  - **LGBMRegressor**  
- **Оценка моделей**:  
  - Сводная оценка с учётом RMSE, времени обучения и скорости предсказания.  
  - Кросс-валидация (**KFold**).  
- **Инструменты**:  
  - Библиотеки **Pandas**, **Numpy**, **Scikit-learn**, **Lightgbm**, **Catboost**.
  - 
## Заключение  
Лучшая модель:
   - Если **скорость критична** — **DecisionTreeRegressor** (RMSE ~1876, обучение за 1.5 сек).  
   - Если **качество важнее** — **CatBoostRegressor** (RMSE ~1629), но учтите долгое время обучения.  
   - **LGBMRegressor** — баланс между качеством и скоростью, но требует настройки гиперпараметров.  

Рекомендуется развернуть **DecisionTreeRegressor** в продакшене для быстрого реагирования, а для точных оценок — **CatBoostRegressor** с периодической перезагрузкой модели.

# Учебные проекты в рамках курса "Специалист по Data Science" от Yandex
В данном репозитории размещены проекты, выполненные мной в рамках обучения на курсе "Специалист по Data Science" от Yandex Practicum

## Инструменты
pandas, numpy, scikit-learn, optuna, seaborn, matplotlib, statsmodels, tensorflow (keras)

## Описание проектов

| Номер | Название проекта                      | Описание                                                              | Используемые инструменты                                                      |
|-------|---------------------------------------|-----------------------------------------------------------------------|------------------------------------------------------------------|
| 13   | [Прогнозирование оттока клиентов (Выпускной проект)](project_13/)| Создание модели для прогноза отказа клиентов оператора связи на основе их персональных данных и использования услуг. | Pandas, Numpy, Seaborn, Scikit-learn, Kmeans, Optuna, Catboost, Phik, Shap      |
| 12   | [Определение возраста покупателей по фото](project_12/)| Разработка системы компьютерного зрения, определяющей возраст покупателей по фото для целевого маркетинга и контроля продажи алкоголя. | Pandas, Numpy, Matplotlib, Seaborn, Tensorflow (Keras, ResNet50)|
| 11   | [Классификация токсичных комментариев](project_11/)| Построение модели для автоматического выявления токсичных комментариев в описаниях товаров интернет-магазина с отправкой их на модерацию. | Pandas, Numpy, Matplotlib, Seaborn, Scikit-learn, Transformers (BERT), NTLK, WordCloud, Hyperopt, LGBMClassifier, PyTorch       |
| 10   | [Прогнозирование заказов такси в аэропортах](project_10/)| Создание модели для прогноза количества заказов такси в аэропортах на следующий час, чтобы оптимизировать привлечение водителей в пиковые периоды. | Pandas, Numpy, Matplotlib, Seaborn, Scikit-learn, Statsmodels, Catboost, LightGBM       |
| 9   | [Предсказание стоимости автомобилей с пробегом](project_09/)| Построение модели для автоматической оценки рыночной стоимости автомобилей с пробегом на основе их технических характеристик и данных. | Pandas, Numpy, Matplotlib, Seaborn, Phik, Scikit-learn, Catboost, LightGBM       |
| 8   | [Выбор локации для нефтяной скважины](project_08/)| Обучение модели для прогнозирования объёмов нефти в скважинах трёх регионов и выбор оптимальной локации с оценкой прибыли и рисков методом Bootstrap. | Pandas, Numpy, Matplotlib, Seaborn, Phik, Scikit-learn, Imblearn, Scipy, Bootstrap       |
| 7   | [HR-аналитика: предсказание уровня удовлетворённости и вероятности увольнения сотрудников](project_07/)| Создание моделей для прогнозирования уровня удовлетворённости сотрудников (от 0 до 1) и вероятности их увольнения, чтобы снизить текучесть кадров и улучшить управление персоналом. | Pandas, Numpy, Matplotlib, Seaborn, Phik, Scikit-learn, Imblearn, Scipy, Optuna, Shap, Permutation Importance, SMOTETomek, PolynomialFeatures       |
| 6   | [Прогноз активности покупателей интернет-магазина "В один клик"](project_06/)| Создание модели для прогнозирования снижения активности клиентов и выделения ключевых сегментов для персонализированных стратегий удержания клиентов. | Pandas, Numpy, Matplotlib, Seaborn, Phik, Scikit-learn, OptunaSearchCV, Shap       |
| 5   | [Прогноз удоя и вкуса молока коров фермерского хозяйства](project_05/)| Разработка моделей машинного обучения для прогнозирования годового удоя и качества молока коров, чтобы минимизировать риски при покупке новых особей для молочного хозяйства. | Pandas, Numpy, Matplotlib, Seaborn, Phik, Scikit-learn, Scipy, Statsmodels       |
| 4   | [Анализ рынка компьютерных игр для интернет-магазина "Стримчик"](project_04/)| Анализ закономерностей, определяющих успешность игры, на основе исторических данных о продажах игр, оценках пользователей и экспертов, жанрах и платформах. | Pandas, Numpy, Matplotlib, Seaborn, Scipy       |

## Задача проекта

На основе данных определить клиента, который собирается уйти.

Тип задачи: бинарная классификация

Целевая метрика: **ROC-AUC не менее 0.85**.

## Описание задачи

Оператор связи «ТелеДом» хочет бороться с оттоком клиентов. Для этого его сотрудники начнут предлагать промокоды и специальные условия всем, кто планирует отказаться от услуг связи. Чтобы заранее находить таких пользователей, «ТелеДому» нужна модель, которая будет предсказывать, разорвёт ли абонент договор. Команда оператора собрала персональные данные о некоторых клиентах, информацию об их тарифах и услугах. Ваша задача — обучить на этих данных модель для прогноза оттока клиентов.

## Навыки и инструменты
В исследовательской части используется кластеризация **KMeans** для поиска целевого сегмента и характеристик клиентов, среди которых наблюдается наибольший отток.
На основе проведенного анализа создаются новые признаки, проводится анализ корреции входящих признаков с целевым с помощью инструмента **phik**.

В качестве моделей машинного обучения рассматривается широкий класс классификаторов, из которых были выбраны следующие представители различных семейств для дальнейшего подбора гиперпараметров:
- LogisticRegression
- RandomForestClassifier
- CatBoostClassifier
- SVC

Кодирование, маштабирование и иная подготовка признаков (например, полиномизация), а также обучение моделей осуществляется внутри **Pipeline**.  

При подборе оптимальных гиперпараметров моделей используются инструменты **GridSearchCV**, **RandomizedSearchCV**, а также инструменты библиотеки **Optuna** для автоматизизированного поиска и визуализации лучших настроек моделей. 

## Заключение

Лучшая модель - **CatBoostClassifier**.

AUC-ROC на тестовой выборке = **0.9237**.

## Рекомендации заказчику

1. Разработать программы удержания для клиентов с короткими контрактами. Например, предлагать скидки или бонусы при переходе на годовые или двухгодовые контракты, системы долгосрочной лояльности.
2. Перевести клиентов на ежемесячную оплату (вместо раза в год или в два года). Это позволит сократить размер одного платежа и снизить негативную реакцию клиентов на единоразовое списание крупных сумм.
3. Ориентировать маркетинговые мероприятия на семейные пары без детей. Отток клиентов происходит в основном в данном сегменте пользователей.
4. Использовать разработанную модель для прогнозирования оттока действующих клиентов.

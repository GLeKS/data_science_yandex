# Исследование коров для молочного хозяйства "Вольный луг"

## Описание задачи  
Молочное хозяйство «Вольный луг» планирует расширить стадо, закупив новых коров у ассоциации «ЭкоФерма». Для минимизации рисков покупки неперспективных животных требуется:  
- Прогнозировать удой коров на основе характеристик корма, генетики и условий выпаса.  
- Оценивать вероятность вкусного молока с акцентом на минимизацию ложноположительных прогнозов. 

## Задача проекта  
**Тип задачи:**  
- Регрессия (прогноз удоя коровы).  
- Бинарная классификация (прогноз вероятности вкусного молока).  

**Цель:**  
Разработать модели машинного обучения для оценки:  
1. Прогноза годового удоя коровы (в кг).  
2. Вероятности получения вкусного молока.  

На основе результатов моделирования отобрать коров, соответствующих критериям:  
- Удой ≥ 6000 кг/год.  
- Молоко вкусное.  

**Целевые признаки:**  
1. `milk_yield_kg` (количественный): годовой удой коровы.  
2. `milk_flavor` (бинарный): "вкусно"/"не вкусно".  

## Навыки и инструменты  
**Подготовка данных:**  
- Обработка пропусков, дубликатов, выбросов.  
- Кодирование категориальных признаков (One-Hot Encoding).  
- Масштабирование числовых признаков (StandardScaler).  

**Модели машинного обучения:**  
- **Регрессия:** Линейная регрессия.  
- **Классификация:** Логистическая регрессия.  
- Подбор гиперпараметров через анализ нелинейностей и взаимодействий признаков.  

**Оценка и оптимизация:**  
- Метрики регрессии: RMSE - основная метрика, R2, MAE - вспомогательные
- Метрики классификации: Precision - основная метрика, Accuracy, Recall - вспомогательные
- Анализ важности признакей (коэффициенты моделей, корреляционный анализ).  

**Инструменты:**  
- Библиотеки: Pandas, NumPy, Scikit-learn, Seaborn, Matplotlib, Phik.  
- Статистический анализ: проверка гипотез, доверительные интервалы.

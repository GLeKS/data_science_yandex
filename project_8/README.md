# Выбор локации для нефтяной скважины

## Задача проекта  
Тип задачи: **регрессия**  
Целевая метрика: **RMSE**  
Критерии принятия решения:  
- **Прибыль** должна быть положительной.  
- **Риск убытков** должен быть <5% (по результатам Bootstrap).  

## Описание задачи  
Компания «ГлавРосГосНефть» планирует бурение новой скважины. Для выбора региона требуется:  
1. Обучить модели для прогнозирования объёмов нефти в скважинах трёх регионов.  
2. Проанализировать прибыль и риски с помощью Bootstrap.  

## Навыки и инструменты  
- **Модели машинного обучения**:  
  - **LinearRegression** (основная модель для всех регионов).  
- **Анализ данных**:  
  - Проверка утечек данных (например, признак **f2** в регионе 1 коррелирует с целевой переменной).  
  - Статистический анализ распределения объёмов нефти.  
- **Оценка рисков**:  
  - Техника Bootstrap (1000 выборок) для расчёта доверительных интервалов.  
- **Инструменты**:  
  - Библиотеки **Pandas**, **Numpy**, **Scikit-learn**.

# Прогноз активности покупателей интернет-магазина "В один клик"

## Задача проекта  
**Тип задачи:** Бинарная классификация  
**Целевая метрика:** **ROC-AUC ≥ 0.9**  
**Цель:**  
1. Предсказать вероятность снижения покупательской активности.  
2. Сегментировать клиентов для персонализированных предложений по удержанию.  

## Описание задачи  
Интернет-магазин «В один клик» столкнулся с снижением активности постоянных клиентов. Цель проекта — разработать модель, которая позволит:  
- Определить клиентов, чья активность снизится.  
- Выделить ключевые сегменты для персонализированных стратегий удержания.  

**Целевой признак:**  
- **покупательская_активность** («снизилась»/«прежний уровень»).  

## Навыки и инструменты  
- **Подготовка данных:**  
  - Кодирование категориальных признаков (OneHotEncoder, OrdinalEncoder).  
  - Масштабирование признаков (StandardScaler).  
- **Модели машинного обучения:**  
  - **SVC** (лучшая модель).  
  - LogisticRegression, DecisionTreeClassifier, KNeighborsClassifier.  
- **Оценка и оптимизация:**  
  - Подбор гиперпараметров через **OptunaSearchCV**, **GridSearchCV**.  
  - Анализ важности признаков (**SHAP, Permutation Importance**).  
  - Корреляционный анализ и сегментация клиентов.  
- **Инструменты:**  
  - Библиотеки **Pandas**, **Numpy**, **Scikit-learn**, **Shap**, **Optuna**.  

## Заключение  
**Лучшая модель:** **SVC**  
- **ROC-AUC:**  
  - На кросс-валидации: **0.915**  
  - На тестовой выборке: **0.9193**   

## Рекомендации заказчику  

### Стратегии удержания для сегментов:  
1. **Сегмент 1: Максимальная доля покупок по акциям + высокий риск снижения активности**  
   - Внедрить **программу лояльности** с бонусами за регулярные покупки.  
   - Персонализировать акции в популярных категориях («Товары для детей», «Косметика»).  

2. **Сегмент 2: Товары с длительным жизненным циклом**  
   - Не рекомендуется фокусироваться: низкая прибыльность (2% клиентов).  

3. **Сегмент 3: Товары для себя/детей + риск снижения активности**  
   - Увеличить **персонализированную рекламу** смежных категорий.  
   - Регулярные уведомления о новинках в любимых категориях.  

4. **Сегмент 4: Высокая прибыльность + риск снижения активности**  
   - Предложить **индивидуальные скидки** и эксклюзивные предложения.  
   - Увеличить частоту коммуникации (электронные рассылки).  

### Общие рекомендации:  
- **Улучшение UX:**  
  - Оптимизировать процесс покупки для сокращения числа **неоплаченных товаров**.  
  - Увеличить среднее время на сайте через персонализированные рекомендации.  
- **Мониторинг:**  
  - Регулярно переподготавливать модель на новых данных.  
  - Аналитика **ошибок_сервиса** и их влияния на уход клиентов.

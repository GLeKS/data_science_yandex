## Описание проекта

Сетевой супермаркет «Хлеб-Соль» внедряет систему компьютерного зрения для анализа фото покупателей в прикассовой зоне. Цель проекта — построить модель, которая по фотографии определит приблизительный возраст человека. Это позволит:

Анализировать покупки и предлагать товары, соответствующие возрастной группе.
Контролировать продажу алкоголя через проверку возраста.

## Задача

Разработать модель машинного обучения для **регрессии** (определения возраста в числовом формате).

**Целевая метрика:** MAE (средняя абсолютная ошибка) **менее 7 лет** .

## Используемые технологии

- **Keras (TensorFlow)** — для построения и обучения нейронной сети.
- **ResNet50** — предобученная нейросеть для извлечения признаков из изображений.
- **Data Augmentation** — аугментация данных для улучшения обобщения модели.
- **Python** — основной язык для реализации и анализа.

## Решение
### Архитектура модели:

1. **Базовая архитектура :**
   - Использован предобученный **ResNet50** для эффективного извлечения признаков из изображений.
2. **Адаптация под задачу :**
   - Добавлен слой **Global Average Pooling** , чтобы снизить размерность данных.
   - Выходной слой с линейной активацией (вместо ReLU) для предотвращения отрицательных прогнозов.
3. **Обучение :**
   - **Функция потерь :** MSE (среднеквадратичная ошибка).
   - **Метрика :** MAE (как целевая для задачи).
   - **Эпохи :** 10, что достаточно для стабилизации обучения.

### Борьба с недостатком данных
Для устранения дисбаланса в категориях 70+ лет были опробованы следующие варианты аугментации:
- Поворот изображений.
- Изменение яркости/контрастности.
- Горизонтальное отражение (модель с горизонтальным отражением показала себя лучше всего, в финальном решении оставлена только эта аугментация).

Это позволило увеличить разнообразие данных и улучшить обобщение модели.

## Результаты
**MAE на валидационной выборке : 6.9592** (менее 7 лет, что соответствует задаче).

Модель достигла целевую метрику уже на 10 эпохах, что демонстрирует эффективность выбранной архитектуры и подхода к аугментации данных.

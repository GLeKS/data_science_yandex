# HR-аналитика: предсказание уровня удовлетворённости и вероятности увольнения сотрудников

## Задача проекта  
**Задача 1 (регрессия):**  
- **Цель:** Предсказание уровня удовлетворённости сотрудников.  
- **Метрика:** SMAPE ≤ 15.  
**Задача 2 (классификация):**  
- **Цель:** Предсказание вероятности увольнения сотрудников.  
- **Метрика:** ROC-AUC ≥ 0.9.  

## Описание задачи  
Компания «Работа с заботой» стремится снизить текучесть кадров и улучшить управление персоналом. Для этого требуется:  
1. Построить модель, предсказывающую уровень удовлетворённости сотрудников (от 0 до 1).  
2. Построить модель, определяющую вероятность увольнения сотрудника.  

## Навыки и инструменты  
- **Подготовка данных**:  
  - Обработка пропусков, категориальных признаков (**OneHotEncoder**, **LabelEncoder**).  
  - Устранение дубликатов и выбросов.  
- **Модели машинного обучения**:  
  - **DecisionTreeRegressor** (задача 1)  
  - **SVC** (задача 2)  
  - Дополнительные модели: **LinearRegression**, **LogisticRegression**, **KNeighborsClassifier**.  
- **Оценка и улучшение моделей**:  
  - Подбор гиперпараметров (**GridSearchCV**).  
  - Полиномизация признаков (**PolynomialFeatures**).  
  - Селектор признаков (**SelectKBest**).  
- **Метрики**:  
  - **SMAPE** (регрессия), **ROC-AUC** (классификация).  
- **Инструменты**:  
  - Библиотеки **Pandas**, **Numpy**, **Scikit-learn**, **Matplotlib**.  

## Заключение  
**Лучшие модели**:  
| Задача                | Модель                  | Метрика (тест) |  
|-----------------------|-------------------------|----------------|  
| Удовлетворённость     | **DecisionTreeRegressor** | SMAPE: **13.5** |  
| Увольнение            | **SVC**                 | ROC-AUC: **0.916** |  

**Ключевые факторы**:  
- **Удовлетворённость**:  
  - Наибольшее влияние: оценка руководителя (коэф. 0.67).  
  - Важные факторы: зарплата, стаж, нарушения.  
- **Увольнение**:  
  - Критичные признаки: уровень должности (48%), удовлетворённость (29%), стаж.  

## Рекомендации заказчику

1. **Обратная связь**:  
   - Регулярные оценки работы и конструктивные беседы с руководителями.  
2. **Карьерный рост**:  
   - Программы обучения и четкие критерии повышения для junior-сотрудников.

   - Упрощение правил для новичков, дополнительные задачи.

   - Использовать модель для выявления сотрудников с низким уровнем удовлетворённости.  
3. **Персональный подход**:  
   - Аналитика сотрудников с низкой оценкой руководителя и частыми нарушениями.

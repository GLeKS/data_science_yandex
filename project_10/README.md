# Прогнозирование заказов такси в аэропортах

## Задача проекта  
Тип задачи: **временной ряд (регрессия)**  
Целевая метрика: **RMSE ≤ 48 (заказок такси в час)**  

## Описание задачи  
Компания «Чётенькое такси» собирает исторические данные о заказах в аэропортах. Цель проекта — спрогнозировать количество заказов на следующий час для оптимизации привлечения водителей в пиковые периоды.  

## Навыки и инструменты  
- **Анализ временных рядов**:  
  - Проверка стационарности (по критерию Дики-Фуллера).  
  - Визуализация тренда, сезонности, шумов.  
  - Обработка нестационарности: создание признаков с лагами, скользящим средним, разностью временных рядов.  
- **Подготовка данных**:  
  - Ресемплирование данных по одному часу.  
  - Создание временных признаков (час, день недели, месяц).  
  - Генерация лагов (до 168 часов для учёта недельной сезонности).  
- **Модели машинного обучения**:  
  - **LinearRegression**  
  - **DecisionTreeRegressor**  
  - **CatBoostRegressor**  
  - **LGBMRegressor**  
- **Инструменты**:  
  - Кросс-валидация для временных рядов (**TimeSeriesSplit**).  
  - Pipeline для автоматизации предобработки и обучения.  
  - Библиотеки **Pandas**, **Numpy**, **Scikit-learn**, **Lightgbm**, **Catboost**, **Statsmodels** 

## Заключение  
Лучшая модель: **LinearRegression**  
- RMSE на кросс-валидации: **42.3**  
- RMSE на тестовой выборке: **46.1**

# Классификация токсичных комментариев для «Викишоп»

## Задача проекта

Обучить модель для классификации комментариев как токсичных или нет.

Тип задачи: **бинарная классификация**

Целевая метрика: **F1 не менее 0.75**.

## Описание задачи

Интернет-магазин «Викишоп» запускает новый сервис, позволяющий пользователям редактировать и дополнять описания товаров, как в вики-сообществах. Клиенты могут предлагать свои правки и комментировать изменения других. Для обеспечения качества контента магазину нужен инструмент, который будет искать токсичные комментарии и отправлять их на модерацию. Ваша задача — обучить модель на наборе данных с разметкой о токсичности правок для классификации комментариев.

## Навыки и инструменты  
- **Предобработка данных**:
   - очистка текста,
   - лемматизация (**WordNet с POS tag**),
   - анализ частотности слов (**WordCloud**)
   - создание новых признаков (**SentimentIntensityAnalyzer**) 
- **Векторизация**:  
  - BOW / TF-IDF с n-граммами (**CountVectorizer** и **TfidfVectorizer**)
  - Эмбеддинги **BERT** для контекстно-ориентированной векторизации.  
- **Модели машинного обучения**:  
  - **LogisticRegression**  
  - **LGBMClassifier**  
- **Инструменты**:  
  - Pipeline для автоматизации векторизации и обучения.
  - Оптимизация гиперпараметров модели с помощью **GridSearchCV**, **RandomizedSearchCV**, **Байесовская оптимизация (алгоритм TPE в библиотеке Hyperopt)**.
  - Кросс-валидация для оценки стабильности моделей.  
  - Библиотеки **scikit-learn**, **lightgbm**, **transformers** (BERT), **hyperopt**.  

## Заключение  
Лучшая модель: **LGBMClassifier с эмбеддингами BERT**  
- F1-мера на кросс-валидации: **0.8895**  
- F1-мера на тестовой выборке: **0.8819**

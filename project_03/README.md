# Анализ сервиса аренды самокатов GoFast

## Описание проекта

В данном исследовании проводится анализ данных популярного сервиса аренды самокатов GoFast, с целью получения ключевых метрик и проверки гипотез, которые могут помочь бизнесу расти и повышать доходность.

**Цель исследования:**
Провести исследовательский и статистический анализ данных о пользователях и их поездках, а также проверить несколько гипотез, касающихся использования подписки Ultra, продолжительности поездок и эффективности маркетинговых акций. Результаты помогут принять обоснованные решения по улучшению сервиса и увеличению прибыли.

## Ключевые задачи

*   Сбор и предобработка данных: приведение типов, обработка пропусков и дубликатов.
*   Исследовательский анализ данных (EDA): распределение пользователей по возрасту, городам, типам подписок, характеристикам поездок.
*   Объединение таблиц для финального анализа и сравнения пользователей с подпиской и без.
*   Подсчёт выручки с разбивкой по типам подписок.
*   Проверка гипотез:
    *   Отличаются ли по времени поездки пользователей с подпиской и без?
    *   Превышает ли среднее расстояние поездок пользователей с подпиской оптимальное значение?
    *   Выше ли помесячная выручка от подписчиков?
    *   Какой тест использовать при анализе обращений в техподдержку до и после обновления?
*   Моделирование вероятностных событий:
    *   Раздача промокодов: какое минимальное количество нужно отправить, чтобы не менее 100 клиентов продлили подписку?
    *   Расчет вероятности того, что push-уведомление откроют не более 399 500 пользователей из 1 млн?

## Используемые инструменты

*   Язык программирования: Python
*   Библиотеки: pandas, numpy, matplotlib, seaborn, scipy.stats
*   Инструменты анализа: Jupyter Notebook
*   Методы статистики: исследовательский анализ данных (EDA), проверка гипотез (t-тесты), работа с распределениями (биномиальное, нормальное)

## Результаты

*   Данные по городам распределены примерно равномерно. Наибольшее число поездок зарегистрировано в **Пятигорске**, наименьшее — в **Москве**.
*   Основная аудитория сервиса — **молодые люди в возрасте 22–28 лет**, со средним возрастом около **25 лет**.
*   **54.4%** пользователей используют сервис **без подписки**.
*   Средняя поездка составляет около **3 км**, а её продолжительность — около **18 минут**.
*   Было обнаружено **95 аномальных записей с высокой скоростью (>400 км/ч)** — возможно, ошибки сбора данных.
*   Пользователи с подпиской тратят больше времени на поездки, чем пользователи без подписки.
*   Помесячная выручка от пользователей с подпиской значительно выше, чем от пользователей без подписки.
*   **Результаты проверки гипотез:**
    *   **Гипотеза 1: Пользователи с подпиской проводят в поездках больше времени, чем пользователи без подписки - ПОДТВЕРЖДЕНА.**
    *   **Гипотеза 2: Среднее расстояние поездки пользователей с подпиской не превышает 3130 метров - НЕ ПОДТВЕРЖДЕНА.**
    *   **Гипотеза 3: Помесячная выручка от пользователей с подпиской выше, чем у пользователей без подписки - ПОДТВЕРЖДЕНА.**
    *   **Гипотеза 4: Для проверки гипотезы о снижении количества обращений в техподдержку после обновления серверов рекомендуется использовать парный t-тест.**
*   При моделировании маркетинговой кампании было установлено:
    *   Чтобы минимизировать риск невыполнения цели (минимум 100 продлений), необходимо разослать не менее **1172 промокода**.
    *   Вероятность того, что push-уведомление откроют не более **399 500 пользователей из 1 млн** — около **15.37%**.

## Выводы

На основе проведённого анализа можно сделать следующие выводы:

*   ✅ **Подписка Ultra выгодна для бизнеса.**
    *   Пользователи с подпиской тратят больше времени на поездки и приносят значительно большую месячную выручку.
*   🎁 **Промокоды — эффективный инструмент удержания.**
    *   Для достижения целевого показателя в 100 продлений подписки рекомендуется разослать не менее **1172 промокода**, чтобы вероятность провала была ниже 5%.
*   📈 **Push-уведомления имеют потенциал роста.**
    *   Вероятность низкого отклика (~15%) указывает на необходимость сегментации и персонализации рассылок.
*   ⚠️ **Требуется проверка аномалий.**
    *   Необходима техническая проверка **95 поездок с аномально высокой скоростью (>400 км/ч)**, так как это может свидетельствовать о сбое в системе учёта данных, что влияет на точность финансовых расчетов.
*   🧭 **Адаптация под локальные особенности.**
    *   В зависимости от города и типа подписки стоит предлагать специальные предложения и персонализированные акции.
